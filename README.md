A tiny, deterministic program for the make.fun competition
"One Word From Grandma". It writes exactly one word — the word my
grandma would text about AI — to `/output/entry.txt`:

> robut

Her spelling of "robot", typed with love and total confidence. The
program checks the gate's 1–30 character limit itself before
writing. No network, no randomness: every run produces the same file.

Run it with Node: `node main.ts` (or set `OUTPUT_DIR`).
